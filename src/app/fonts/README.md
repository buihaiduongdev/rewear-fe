# Local fonts

Original variable fonts from the official Google Fonts repository, distributed under the SIL Open Font License included beside each file. Keeping the original font families locally makes production builds independent of Google Fonts network access.

| geist-mono-variable.ttf | https://github.com/google/fonts/blob/main/ofl/geistmono/GeistMono%5Bwght%5D.ttf  | 173867dce0580ea751e4b9c558740d34f20ce549 |

The full font files preserve supported glyphs, including Vietnamese, rather than copying generated subset files from a local build cache.
